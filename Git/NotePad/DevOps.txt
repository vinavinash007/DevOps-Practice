What is a Docker ?
- Docker is a containerization platform for develpoing, packaging, shipping and running applications.
Docker is an open-source platform that uses operating system-level virtualization to deliver software in lightweight, isolated packages called containers.

why do we need a Docker ?
-  developer send the packaging image to tester so that there is no conflict in running the file 
Docker solves environment inconsistency

what is a containers?
A container is a lightweight, isolated package that holds an application and everything it needs to run.




Comparison between Docker and VMs

+-------------------------+     +-------------------------+

| App A  | App B  | App C |     |  App A  |  App B  |  App C  |
| Libs   | Libs   | Libs  |     |  Libs   |  Libs   |  Libs   |
+-------------------------+     +---------+---------+---------+

|     Docker Engine       |     | Guest OS| Guest OS| Guest OS|
+-------------------------+     +---------+---------+---------+

|     Host OS Kernel      |     |        Hypervisor       |
+-------------------------+     +-------------------------+

|    Physical Hardware    |     |    Physical Hardware    |
+-------------------------+     +-------------------------+
    DOCKER CONTAINERS                    VIRTUAL MACHINES
	
	
	
Docker isolates at the app level, while VMs isolate at the hardware leve

Dockerfile: A simple text file containing sequential commands (like FROM, RUN, and COPY). 
It acts as a precise recipe to build a Docker image.Docker Image: A read-only, multi-layered snapshot containing the application code, runtime libraries, and environment variables. 
It serves as the template for containers.Docker Container: A live, runnable instance of an image. 
It is an isolated sandbox running your application process on the host machine.Docker Registry / Hub: A storage and distribution system for Docker images. 
Docker Hub is the default public cloud registry where developers share pre-built images
